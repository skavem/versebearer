Итог

Где VerseBearer выигрывает

  • Порог входа для оператора. Четыре вкладки против 75 групп настроек. Человека можно посадить за программу за пять минут без обучения.
  • Вес и запуск. Один Go-бинарник на системном WebView вместо полного Chromium — меньше дистрибутив, быстрее старт, меньше памяти.
  • Целостность данных. SQLite с транзакциями и миграциями вместо россыпи JSON-файлов; шрифты и фоны лежат в той же базе, переносится одним файлом.
  • Заточка под задачу. Синодальный текст, русский интерфейс, куплеты как первичная сущность — ровно то, что нужно на служении, без слоя абстракций «шоу → раскладка → слайд → элемент».
  • Прокликиваемый оверлей. Готовый режим «текст поверх рабочего стола» под захват в OBS без настройки key/alpha-выходов.
  • Защита от показа на монитор оператора — мелочь, которой у FreeShow в явном виде нет.

Где отставание принципиальное

  • Нет медиа вообще. Ни видеофона, ни звука, ни картинки-иллюстрации, ни камеры. Для многих общин это отсекающее требование.
  • Нет плана служения. Оператор ищет каждую песню вручную по ходу — самая частая причина заминок на сцене.
  • Нет удалённого управления. Ни телефона-пульта, ни экрана для музыкантов, ни второго оператора.
  • Нет импорта. Песенник нельзя перенести из ProPresenter, OpenLP или EasyWorship — переезд означает ручной ввод.
  • Нет экспорта и бэкапа из интерфейса. Единственная копия — файл базы, о котором пользователь должен знать сам.
  • Один перевод Библии. Ни параллельных версий, ни поиска, ни номеров стихов, ни ссылки на экране.
  • Нет лицензии в репозитории — формально код нельзя ни распространять, ни принимать в него вклад.
